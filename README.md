# LapTrinhUngDungWeb_DuAneShop_Mau

Dự án Lập Trình ứng Dụng Web - Blazor E-Commerce App Demo

## Giới thiệu
Dự án được xây dựng bằng .NET / Blazor Component Architecture.

## Cấu trúc dự án
- `BlazorApp1_Demo`: Dự án mã nguồn Blazor chính và các Use Cases, DataStore.
- `Components`: Các Razor Components tái sử dụng.
- `Lecturer Slides`: Slide bài giảng tham khảo.
- `sequence_diagrams.md`: Sơ đồ trình tự các chức năng.
